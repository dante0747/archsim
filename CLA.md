## How to sign

When You open Your first pull request, a bot asks You to sign. Sign by commenting on the pull
request with this sentence, exactly:

```text
I have read the ArchSim Contributor License Agreement and I hereby sign it.
```

The bot records Your GitHub user name and ID, the date, the pull request and this agreement's
version in the repository's `cla-signatures` branch. One signature covers every later Contribution
You submit under this version.
