# Development checks (in-sample)

Generated by `benchmarks/report.py --dev` from `benchmarks/results/dev/`, which `uv run python benchmarks/run.py resimulate` writes. Each row is a kept benchmark run: its calibration passes are turned into model inputs again with today's `run.py`, and its measured load steps are simulated with the engine in each column. These checks are designed after the measurements were seen, so they show what a model change does on data it may have been tuned on. They are never predictions, and neither docs/validation.md nor the /accuracy page shows them.
