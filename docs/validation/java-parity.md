## How it was measured

- The baselines: `scripts/export_simulation_baselines.py` simulated every template case in full on the frozen engine, with the workload's seed and the 19 after it ([ADR-0052](../adr/0052-record-the-frozen-engines-simulation-baselines-once.md)).
- The Java runs: `./gradlew :archsim-engine:parity -Parchsim.parity.out=docs/validation` simulated the same runs (4 at a time) and wrote `simulation-parity.json`; the `javaSeconds` it records is not a speed figure.
- The knees: `BENCH_ENGINE=java uv run python benchmarks/run.py resimulate` wrote `benchmarks/results/dev/0.16.0-java/` before the Java engine had a version of its own (it names the folder by its version now), and the same harness on the frozen engine, `uv run python benchmarks/run.py resimulate --label 0.16.0-port`, `benchmarks/results/dev/0.16.0-port/`, each over every kept run with a two-pass calibration, the only kind with a knee to re-simulate (`dev/0.16.0/` predates the spread anchor every check now derives, `dev/0.16.0-w29/` the held-out runs).
